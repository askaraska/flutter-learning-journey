# Day 1 Revision Notes — Dart & Flutter

## Dart Fundamentals

- `String`: stores text.
- `int`: stores whole numbers.
- `double`: stores decimal numbers.
- `bool`: stores `true` or `false`.
- `var`: lets Dart infer the variable's type.
- `final`: can be assigned only once; its value can be determined at runtime.
- `const`: represents a compile-time constant.

## Functions

- Parameters are variables declared in a function definition.
- Arguments are the actual values passed when calling a function.
- `return` sends a value back to the caller.
- `print()` displays output in the console.
- `void` means the function does not provide a usable return value.

## Lists, Loops & Conditions

- A list stores multiple values.
- List indexing starts at `0`.
- `.length` returns the number of elements.
- `.add()` adds an element.
- `if` and `else` execute different branches depending on a condition.
- `for` and `for-in` loops repeat operations.

## Flutter Fundamentals

- `main()` is the Dart entry point.
- `runApp()` starts the Flutter widget tree.
- `MaterialApp` provides the app's Material Design structure.
- `Scaffold` provides a standard page layout.
- `AppBar` displays the top application bar.
- `Column` arranges children vertically.
- `Container` can provide decoration, padding, and sizing.
- `ElevatedButton` creates a button.
- `onPressed` defines the button's action.
- `debugPrint()` writes diagnostic output to the debug console.

## Important Reminder

A function call executes the function. `return` sends a result back to the caller; it does not mean "print."
