# Day 1 — Dart Fundamentals & First Flutter UI

## Objective

Learn the basics of Dart and build a simple interactive Flutter dashboard.

## Concepts Practiced

### Dart
- Variables and data types
- `var`, `final`, and `const`
- Functions, parameters, and return values
- Lists and loops
- Conditional statements

### Flutter
- `main()` and `runApp()`
- `MaterialApp` and `Scaffold`
- `AppBar`, `Center`, `Padding`, and `Column`
- `Container`, `Icon`, and `Text`
- `ElevatedButton` and `onPressed`
- `debugPrint()`

## Practical Result

Built and ran a custom Flutter learning dashboard in Chrome. The dashboard displays learning information and includes a button that prints a completion message in the debug console.
