# Flutter Learning Journey

A hands-on journey to learning Flutter and Dart through practical exercises, UI development, and mini-projects.

## About This Repository

This repository documents my progress as I learn Flutter app development. Each day's folder contains learning notes, practical exercises, and project updates.

## Day 1 — Dart Fundamentals & First Flutter UI

**Status:** Completed

### Topics Covered
- Dart variables and data types
- `var`, `final`, and `const`
- Functions, parameters, and return values
- Lists, loops, and conditional statements
- Flutter entry point: `main()` and `runApp()`
- Widgets: `MaterialApp`, `Scaffold`, `AppBar`, `Column`, `Container`, and `ElevatedButton`
- Building and running a custom Flutter dashboard

### Project Features
- Custom learning dashboard
- Flutter widgets arranged in a vertical layout
- Button interaction with debug output

### Run the Project

Install Flutter and configure the required development tools, then run:

```bash
flutter pub get
flutter run
```
